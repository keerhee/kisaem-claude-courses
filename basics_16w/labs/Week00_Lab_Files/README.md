# 0주차 오리엔테이션 실습 파일 — 사전 환경 세팅과 대규모 실습 운영

| 파일 | 대상 | 용도 |
|---|---|---|
| check_env.py | 수강생 | 파이썬 · 패키지 · 명령 · 키 · (선택) 접속 점검 → env_report.txt |
| requirements.txt | 수강생 | 과정 전체 파이썬 패키지 |
| Learner_Checklist.md | 수강생 | 주차별 마감이 있는 준비 체크리스트 |
| Operator_Guide.md | 운영자 | 규모별 조교 · 일정 · 당일 장치 · IT 협조 |

수강생: `pip install -r requirements.txt` → `python check_env.py` (회사망이면 `--net` 추가)
키 값은 화면과 보고서에 표시되지 않습니다.
