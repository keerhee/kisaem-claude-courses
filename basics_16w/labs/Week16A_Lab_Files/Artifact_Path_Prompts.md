# 경로 A — 코드 없이 Claude 앱의 Artifact로 만들기

Claude Code가 아직 없는 자리(부서 PC · 회의 직전)에서는 Claude 앱 대화창에서 같은 화면을 만듭니다.
결과는 Artifact 페이지(비공개 링크)로 열리고, HTML 파일로 내려받을 수 있습니다.
**경로 A로 시안을 확정하고, 매주 다시 돌릴 화면은 경로 B(Claude Code + 스크립트)로 옮깁니다.**

## 1. 대시보드 시안 (공개 자료 · 가상 자료만)

엑셀에서 '약정·NAV' 시트와 펀드별 납입·분배 합계 표를 복사해 붙여 넣은 뒤:

```text
아래 PRD와 표만으로 한 화면짜리 대시보드 Artifact를 만들어 줘.
[PRD 일곱 칸 붙여넣기]
[표 붙여넣기]
- 숫자는 표의 값을 그대로 쓰고 바꾸지 마. 계산이 필요한 TVPI는 표 아래에 계산식과 함께 따로 보여 줘.
- 맨 위에 기준일과 출처를 적어 줘.
- 외부 라이브러리 없이 HTML과 SVG만으로 그려 줘.
```

## 2. 업무 MVP 시안

```text
아래 PRD대로 캐피털콜 검토 화면 시안을 Artifact로 만들어 줘.
[PRD 일곱 칸 붙여넣기]
[명단 20행 붙여넣기]
- 왼쪽 목록 · 가운데 규칙 결과 · 오른쪽 승인/보류/반려 버튼과 개입 기록, 세 칸으로.
- 판정 규칙은 코드 맨 위 RULES 한 곳에 모아 줘.
- 만든 뒤 13번이 '차단'으로 나오는지, 요청액 합계가 149.7인지 표로 확인해 줘.
```

## 경로 A에서 지킬 것
- 내부 자료는 회사가 승인한 계정(Team · Enterprise)에서만 붙여 넣습니다. 공유 링크는 받은 사람 누구나 엽니다.
- Artifact의 숫자는 대화 속 계산 결과입니다. **원자료 합계 1개와 표본 3건을 직접 대조**한 뒤에만 보여 줍니다.
- 고칠 때는 "TVPI 막대만 진한 색 하나로"처럼 고칠 곳만 말합니다(4주차 수정 요청과 같은 방식).
