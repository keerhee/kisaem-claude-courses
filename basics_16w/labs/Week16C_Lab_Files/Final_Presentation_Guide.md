# 최종 발표 안내 (16주차)

## 형식 — 1인 5분 + 질의 2분
1. 문제 (30초): 어떤 반복 업무였고 매주 몇 시간이 들었나
2. 전·후 (1분): 이전 방식과 지금 방식 비교
3. 시연 (2분): 실제 실행 화면 — 녹화 영상 가능. 16주차 1부에서 만든 대시보드 · HTML MVP 화면을 써도 된다(PRD 한 장을 함께 보여 준다)

> **발표 영상으로 내도 됩니다.** 16주차 2부 방식(대본 → 장면 → 문장 나레이션)으로 만든 5분 이내 영상을 1–5단계 대신 상영하고, 질의 2분은 현장에서 받습니다. 영상 · 자막(srt) · 대본(script.json)과 점검표(Video_Checklist.md)를 함께 냅니다.
4. 검증 장치 (1분): 숫자를 어떻게 대조하고 누가 승인하나
5. 거버넌스 (30초): AI 업무 대장 한 줄

| 항목 | 배점 | 보는 것 |

| 자동화 수준 | 25 | 사람 개입이 실제로 줄었나 |
| 검증 장치 | 25 | 대조 · 판정 기록이 있는가 |
| 재현성 | 20 | CLAUDE.md · git · 실행 명령으로 남이 다시 돌릴 수 있나 |
| 거버넌스 | 15 | 자료 등급 · 승인자 · 점검 주기가 정해졌나 |
